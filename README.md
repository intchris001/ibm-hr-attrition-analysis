# IBM HR Employee Attrition Analysis

Notebook-based exploratory analysis of employee attrition, satisfaction, commute distance, travel frequency, and compensation patterns using Python data tools.

## Data

The source CSV is not included. Place the IBM HR Analytics attrition dataset at `data/WA_Fn-UseC_-HR-Employee-Attrition.csv` before running the notebook.

## Tools

Python, pandas, NumPy, Matplotlib, Seaborn.
